⚗️ The S-Divergence Loss
A 2-parameter family that generalises both KL divergence (Cross-Entropy) and β-divergence (DPD). The robustness mechanism is elegant: each sample's gradient is automatically weighted by the model's own confidence.

Per-sample loss (classification, K classes)

ℓ_{β,λ}(y, p) = (1/A) · Σₖ pₖ^{β+1} − (1+β)/(A·B) · pᵧ^B

where: A = 1 + λ(1−β) > 0, B = β − λ(1−β) > 0
β=0, λ=−1 → reduces exactly to Cross-Entropy (CCE)
λ=0 → reduces to Density Power Divergence (DPD / β-divergence)
β=0.05, λ=−0.8 → paper default. Robust sweet spot.
Gradient ∝ pᵧ^β → mislabeled samples auto-downweighted. No outlier detection needed.
